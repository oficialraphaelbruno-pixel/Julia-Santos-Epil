# Planejar campanha

Pré-requisitos a confirmar com a usuária: período, serviço(s), verba máxima, oferta/desconto (se houver), meta.

Execute a skill `coordenar-escritorio` e produza a tabela de fases:

| Fase | Responsável | Entrega | Status |
|---|---|---|---|
| Ideia | usuária | pedido registrado | concluída |
| Estratégia | diretor-marketing | conceito, público, canais | |
| Viabilidade | diretor-financeiro | margem, ponto de equilíbrio, verba aprovada | |
| Criativos | copywriter + marketing | textos, briefings visuais (Canva) | |
| Aprovação | usuária | itens aprovados/rejeitados | pendente |
| Execução | trafego / whatsapp_crm | somente itens aprovados | bloqueada até aprovação |
| Conversão | gestor-comercial | acompanhamento de leads → agendamentos | |
| Análise | analista-dados | resultado vs meta, CAC, ROAS | |

Inclua: cronograma, orçamento por canal, UTMs, critérios de pausa/escala, riscos e lista de aprovações (tipo, conteúdo exato, custo).
